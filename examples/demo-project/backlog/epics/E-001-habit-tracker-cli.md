## Goal
A small command-line tool where a user adds habits, checks them off each day and
sees their streaks. Fictional demo project for backlog-board.

## Scope / Non-goals
In: local storage, add/check-off commands, streaks, a weekly summary.
Out: sync between machines, a GUI, reminders.
